Boards are for work that moves. Notes are for what you know; a board is for what you are doing about it.

The **Learn Lorestead** board is on the Boards page - a short checklist with two lists, To Try and Done. Drag a card across when you finish it.

## The parts of a board

- **Boards** sit in a flat list on the left. The add icon creates one and starts a rename; rename later with `F2`, a double-click, or the right-click menu.
- **Lists** are the vertical lanes. Drag a list by its header to reorder it. Double-click the title to rename it; hover the header for rename and delete buttons.
- **Cards** are tasks. The add button at the bottom of a list creates one and opens it. Drag a card to move or reorder it; right-click to open or delete it.

## Inside a task

A task has a title, a markdown body with the same toolbar and `[[` autocomplete as a note, its own attachments, and a **linked notes** field.

There are no due dates, labels, or comments. Sub-tasks are a checkbox list in the body:

- [x] Decide the scope
- [ ] Write it down
- [ ] Ship it

## Linked notes

Link a note to a task and the two stay connected both ways: the note's backlinks tool lists the task, with the board and list it sits in.

Every card on the Learn Lorestead board links to a note in this tour, so you can see it work before you try it.

Deleting a task asks once, then it is gone - boards have no trash. Notes do, so a linked note is never lost by accident.

## Agents work boards too

An agent can create cards, update them, move them between lists, and link notes to them. Its edits carry its device name with an `-mcp` suffix, so a card an agent moved says so. Give an agent a project board and it can pick up a card, do the work, and move it to Done - [Agents & MCP](note://019b76da-a800-7000-8000-000000000007) shows how to connect one.

Search finds cards and boards as well as notes. [Search & Links](note://019b76da-a800-7000-8000-000000000005) has the details.
