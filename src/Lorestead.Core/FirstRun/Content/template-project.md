A starting point for a piece of work that will run longer than a day. Overview for what it is, Ideas for what it might become, Log for what actually happened.

Use it from the template icon above the tree, or right-click a note and choose **Add from template** to put the copy underneath that note.

Delete the parts you do not want - the copy is yours, and changing it does not change the template.
