Boards are for work that moves. Notes are for what you know; a board is for what you are doing about it.

The **Learn SylvaNote** board is on the Boards page - a short checklist with two lists, To Try and Done. Drag a card across when you have done it.

## How a board is put together

- **Boards** are listed flat on the left. The add icon creates one and starts an inline rename; `F2` or a double-click renames later.
- **Lists** are the vertical lanes. Drag them to reorder, or use the edit icon that appears when you hover a list title.
- **Cards** are tasks. The add button at the bottom of a list creates one and opens it for editing. Drag a card between lists or within a list to reorder it.

## Inside a task

The task dialog has a title, a markdown body with the same toolbar and `[[` autocomplete as a note, its own attachments, and a **linked notes** field.

There are no due dates, labels, or comments. Sub-tasks are just a checkbox list in the body, which is enough:

- [x] Decide the scope
- [ ] Write it down
- [ ] Ship it

## Linked notes

Linking a note to a task is how the doing side and the knowing side stay connected. The link shows on the note as well: open a linked note and its backlinks tool lists the task, along with the board and list it sits in.

Every card in the Learn SylvaNote board links to a note in this tour, so you can see it working before you link anything yourself.

Deleting a task removes it immediately - boards have no trash. Notes do, so a note linked from a task is never lost by accident.
